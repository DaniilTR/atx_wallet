# ATX Wallet

Кроссплатформенное мобильное приложение для безопасного хранения, отправки и конвертации криптоактивов. Приложение разработано на Flutter (Dart) и работает на Android и iOS; серверная часть реализована на Node.js с базой данных MongoDB.

**Ключевая идея:** предоставить быстрый, интуитивный и защищённый кошелёк, пригодный как для повседневных пользователей, так и для корпоративных сценариев, где требуются надёжность и контроль доступа. Надёжная кроссплатформенная Flutter-реализация кошелька с продуманной архитектурой безопасности, поддержкой HD-кошельков (BIP-39/BIP-32/BIP-44), подписанием транзакций на устройстве, биометрией и встроенным помощником для повышения защиты от фишинга.

**Основные преимущества**
- **Кроссплатформенность:** единая кодовая база на Flutter для Android и iOS — быстрая доставка фич и единый UX.
- **Безопасность на первом месте:** генерация seed-фраз и иерархическая (HD) генерация ключей в соответствии со стандартами BIP-39 / BIP-32 / BIP-44; адреса проверяются по EIP-55.
- **Локальная защита ключей:** приватные ключи и seed зашифрованы и хранятся локально; операции подписи выполняются на устройстве, без передачи приватных данных на сервер.
- **Быстрый доступ:** поддержка биометрической аутентификации (FaceID / Fingerprint).
- **Мульти-кошелёк и мульти-блокчейн:** управление несколькими кошельками, работа с несколькими цепями и валютами, конвертация активов.
- **AI-помощник и защита от фишинга:** встроенные механизмы помощи пользователю при проверке ссылок/адресов и обнаружении подозрительных сценариев.
- **Интеграции и расширяемость:** модульный дизайн клиентской части, позволяющий добавлять новые блокчейны и сервисы цен.

**Функциональность**
- Создание и восстановление кошельков через seed-фразу.
- Управление несколькими кошельками и счетами.
- Отправка/получение транзакций с локальной подписью.
- Конвертация активов с использованием сервиса цен.
- История транзакций и уведомления о статусе.
- Биометрический вход и PIN как резервный метод доступа.
- Экспорт/импорт кошельков (безопасно и с шифрованием).

**Архитектура и стек технологий**
- Клиент: Flutter (Dart) — единая кодовая база для Android и iOS.
- Сервер: Node.js — API, вспомогательные сервисы, интеграции с провайдерами блокчейн-нод.
- Хранилище: MongoDB — метаданные, профили пользователей, черновые данные (без приватных ключей в открытом виде).
- Безопасность: BIP-39 / BIP-32 / BIP-44, EIP-55, хеширование паролей (bcrypt), симметричное шифрование локального хранилища, JWT для сессий на сервере.

> Реализация безопасности спроектирована так, чтобы приватные ключи и seed-фразы никогда не покидали устройство в виде открытого текста; сервер хранит только необходимую мета-информацию.

**Для разработчика — как собрать и запустить**
Требования: установленный Flutter SDK, Android SDK (или Xcode для iOS), Node.js и MongoDB (для локального запуска серверной части).

Пример простого запуска приложения (dev):
```bash
# клиент
flutter pub get
flutter run

# сервер (в отдельной ветке )
cd server
npm install
npm run dev
```

Сборка релиза для Android:
```bash
flutter build apk --release
```
Для iOS: собирать через Xcode (архивация) или `flutter build ios` при наличии macOS.
