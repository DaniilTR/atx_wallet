Политика конфиденциальности ATX

Дата последнего обновления: 07.04.2026

ATX — локальная утилита для аналитики сетевых данных и управления криптографическими ключами на устройстве пользователя. Это означает, что мы не храним ваши секретные ключи или секретные фразы доступа на наших серверах и не можем восстановить доступ к вашим локальным данным в случае их утраты.

Ниже описано, какие данные обрабатывает приложение, где они хранятся, а также какие данные могут передаваться третьим сторонам при работе приложения.

2) Какие данные обрабатывает приложение

2.1. Данные, которые вы вводите

  • Имя пользователя (никнейм).
  • Email (если вы указываете его при регистрации).
  • Пароль (используется локально для доступа к защищённому хранилищу на устройстве).

Важно: приложение реализует локальную аутентификацию и хранит данные сессии на устройстве.

2.2. Данные блокчейна

  • Публичные сетевые идентификаторы (например, адреса), которые вы вводите/используете в приложении.
  • Публичная статистика по указанным идентификаторам и отображаемые индикаторы/графики, получаемые из внешних источников.
  • Локальная история действий (например, записи о выполненных действиях внутри приложения).

2.3. Данные устройства/технические данные

Приложение делает сетевые запросы к публичным API и RPC-узлам. Эти сервисы могут видеть:

  • IP-адрес и сетевые метаданные запроса;
  • параметры запросов (например, сетевой адрес при получении публичной статистики);
  • user-agent (если он передаётся HTTP-клиентом).

Мы не добавляем скрытых идентификаторов трекинга в эти запросы.

2.4. Камера (QR-сканирование)

Приложение может запрашивать доступ к камере (например, разрешение android.permission.CAMERA) для функции сканирования QR-кодов (ввод адресов/данных кошелька без ручного набора).

  • Кадры с камеры используются только во время сканирования и обрабатываются локально на устройстве.
  • Мы не сохраняем фото/видео с камеры и не отправляем изображение на наши серверы.
  • Вы можете не предоставлять доступ к камере и вводить данные вручную; также разрешение можно отозвать в настройках ОС.

3) Что мы НЕ собираем

  • Мы не собираем и не отправляем на наши серверы ваши секретные ключи или секретные фразы доступа.
  • Мы не проводим KYC/верификацию личности.

4) Где хранятся данные

4.1. Хранение на устройстве

  • Секретные данные (ключевой материал/секретные фразы) могут храниться на устройстве в зашифрованном виде с использованием защищённого хранилища (например, flutter_secure_storage).
  • Производный ключ для расшифровки защищённого хранилища получается из пароля пользователя (KDF) и не отправляется на сервер.
  • Криптографические операции (например, генерация подписей на устройстве) выполняются локально; секретные данные не передаются на сервер.

4.2. Биометрия

Если вы включаете биометрический вход, приложение использует системные механизмы платформы (например, Android Keystore/biometric prompt). Биометрические данные не передаются приложению напрямую и не хранятся в приложении: управление биометрией выполняет ОС.

5) Передача данных третьим сторонам

Для работы кошелька приложение обращается к внешним источникам данных:

  • Публичные API и сетевые узлы (для получения публичной статистики и выполнения сетевых запросов, сформированных приложением).
  • CoinGecko API (для публичных индикаторов/графиков) — напрямую или через ваш прокси/сервер кэша (если он настроен).
  • blockstream.info API (для публичной статистики по указанным сетевым адресам).

При этих запросах третьи стороны получают IP-адрес и параметры запроса. Мы рекомендуем использовать надёжные источники, HTTPS и при необходимости собственный прокси.

5.1. AI-ассистент (если включён)

В некоторых сборках может присутствовать AI-чат. Если функция включена, сообщения пользователя отправляются на настроенный сервер AI-ассистента.

  • По умолчанию AI-ассистент может быть выключен.
  • Мы рекомендуем включать AI только при наличии HTTPS, ограничений по частоте запросов и политики хранения/удаления данных на сервере.

6) Безопасность

Мы используем разумные меры защиты данных на стороне клиента:

  • шифрование секретных данных в защищённом хранилище;
  • локальное выполнение криптографических операций на устройстве;
  • ограничения на скриншоты для чувствительных экранов (если поддерживается платформой).

Однако безопасность также зависит от пользователя:

  • храните секретные данные в безопасном месте;
  • не копируйте секретные данные в небезопасные места;
  • используйте экранную блокировку и биометрию, если возможно;
  • не устанавливайте приложения из непроверенных источников.

7) Ваши права

Вы можете:

  • удалить приложение, чтобы удалить локальные данные на устройстве;
  • очистить данные приложения через настройки ОС.

Так как приложение хранит и обрабатывает секретные данные локально, мы не можем «восстановить» доступ к вашим локальным данным без ваших секретов/данных доступа.

8) Изменения политики

Мы можем обновлять эту политику. Актуальная версия всегда доступна по ссылке, указанной в приложении и в Google Play.
